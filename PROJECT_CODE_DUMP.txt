# Automated Distributor Analytics

Це навчальний проект, створений для демонстрації повнофункціональної веб-системи обліку продажів, складу та фінансової аналітики для дистриб'юторів.

## Огляд проекту

Проект складається з двох частин:

- `backend/` — Node.js + Express API з SQLite, JWT авторизацією, ролями користувачів та можливістю генерації звітів у PDF/Excel.
- `frontend/` — React + Vite клієнтська частина з інтерактивною панеллю, графіками, таблицями та підтримкою світлої/темної теми.

## Особливості

- Авторизація через JWT
- Рольова модель: `Admin` та `Analyst`
- Адмінська сторінка для створення, редагування і видалення користувачів
- Продажі з фільтрацією, сортуванням і посторінковою навігацією
- Аналітика продажів з графіками та KPI
- Управління складом із підрахунком залишків та експортом CSV
- Факторний аналіз, фінансові розрахунки та генерація звітів
- Підтримка української мови в інтерфейсі та демонстраційних даних

## Технології

- Backend: Node.js, Express, Knex, SQLite, JWT, bcrypt, PDFKit, ExcelJS
- Frontend: React, Vite, React Router, Axios, Bootstrap, Recharts, React Toastify
- Інструменти: concurrently для одночасного запуску серверів

## AI-аналітик

Доданий модуль AI-аналітика: бекенд формує контекст з наявних фінансових показників та факторного аналізу і відправляє його зовнішній AI API для інтерпретації.


Налаштування environment variables (див. `.env.example`):


Ця реалізація використовує локальний Ollama через REST API (жодних платних API та ключів). React не звертається безпосередньо до Ollama — всі запити проходять через бекенд. AI не має прямого доступу до БД — бекенд збирає дані, формує контекст і передає лише ці значення для пояснення. Результат повертається у структурованому JSON з полями: `summary`, `positiveFactors`, `negativeFactors`, `risks`, `recommendations`, `factorAnalysisExplanation`.

## Локальний AI-аналітик (Ollama)

Цей проєкт використовує локальний Ollama REST API для безплатного запуску AI-моделі локально. React не звертається безпосередньо до Ollama — усе проходить через бекенд.

Кроки (коротко):

1. Встановіть Ollama за офіційною інструкцією: https://ollama.com/docs
2. Завантажте рекомендовану модель (приклад):

```powershell
ollama pull <model-name>
```

3. Запустіть Ollama локально (див. офіційну інструкцію); зазвичай:

```powershell
ollama serve
```

4. Налаштуйте `.env` (див. `.env.example`):

```text
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=<model-name>
```

5. Запустіть бекенд і фронтенд як зазвичай.

Тестування: Виконайте `POST /api/ai/analyze` або натисніть кнопку `✨ Виконати AI-аналіз` у Dashboard.

Примітка: назву моделі вибирайте відповідно до моделі, яку ви завантажили в Ollama. Немає API key — все локально.

Backend (Express + SQLite) for Distributor Analytics

Quick start:

1. Install dependencies

```powershell
cd backend
npm install
```

2. Create `.env` from `.env.example` and adjust `JWT_SECRET` if desired.

3. Run migrations and seeds (Knex):

```powershell
npx knex migrate:latest --knexfile knexfile.js
npx knex seed:run --knexfile knexfile.js
```

4. Start dev server:

```powershell
npm run dev
```

API docs (Swagger): http://localhost:4000/api/docs

Useful endpoints:
- `POST /api/auth/login` — login (use demo users in seeds)
- `GET /api/analytics/dashboard` — dashboard KPIs
- `GET /api/sales` — list sales
- `POST /api/reports/generate/pdf` — generate PDF
- Swagger and Authorization:
	- API docs are available at `http://localhost:4000/api/docs`.
	- The docs include a Bearer (JWT) security scheme — obtain a token via `POST /api/auth/login` and use it when calling protected endpoints.

- `POST /api/reports/export/sales-csv` — generate CSV export for sales (body: filters)

Files generated by reports are stored in `public/reports` and recorded in `reports` table.

function linspace(start, end, n) {
    const res = [];
    for (let i = 0; i < n; i++) {
        const t = i / (n - 1);
        res.push(start + (end - start) * t);
    }
    return res;
}

        // Number of sales (total count)

        const turnover = turnoverRow && turnoverRow.sum ? Number(turnoverRow.sum) : 0;

        // Inventory totals
        const stockRow = await knex('products').sum('stock as stock').first();
        const stockTotal = stockRow && stockRow.stock ? Number(stockRow.stock) : 0;

        // Monthly revenue for last 12 months
        const months = await knex.raw(
            `SELECT strftime('%Y-%m', sale_date) as month, SUM(total_price) as revenue FROM sales WHERE sale_date >= date('now','-12 months') GROUP BY month ORDER BY month`);

exports.create = async (req, res, next) => {

        const { product_id, quantity, unit_price } = req.body;

        const product = await trx('products').where({ id: product_id }).first();

        if (product.stock < quantity) throw new Error('Insufficient stock');

        const price = unit_price || product.price;

    } catch (err) {

const jwt = require('jsonwebtoken');
const JWT_SECRET = process.env.JWT_SECRET || 'secret123';

function authenticate(req, res, next) {
    const auth = req.headers.authorization;
    if (!auth) return res.status(401).json({ message: 'No token provided' });
    const token = auth.split(' ')[1];
    try {
        const payload = jwt.verify(token, JWT_SECRET);
        req.user = payload;
        next();
    } catch (err) {
        res.status(401).json({ message: 'Invalid token' });
    }
}

function authorize(roles = []) {
    return (req, res, next) => {
        if (!req.user) return res.status(401).json({ message: 'Unauthorized' });
        if (typeof roles === 'string') roles = [roles];
        if (roles.length && !roles.includes(req.user.role))
            return res.status(403).json({ message: 'Forbidden' });
        next();
    };
}

module.exports = { authenticate, authorize };

const http = require('http');
const https = require('https');
const { URL } = require('url');
const knex = require('../db/knex');
const factorService = require('./factorService');

const OLLAMA_BASE_URL = process.env.OLLAMA_BASE_URL || 'http://localhost:11434';
const OLLAMA_MODEL = process.env.OLLAMA_MODEL || 'llama2';
const OLLAMA_TIMEOUT_MS = Number(process.env.OLLAMA_TIMEOUT_MS) || 120000;

function safeParseJson(text) {
    try {
        return JSON.parse(text);
    } catch (e) {
        // try to extract JSON block
        const m = text.match(/\{[\s\S]*\}/);
        if (m) {
            try { return JSON.parse(m[0]); } catch (e2) { return null; }
        }
        return null;
    }
}

function callOllama(messages) {
    const systemMessage = messages.find(message => message.role === 'system');
    const userMessages = messages.filter(message => message.role !== 'system');
    const prompt = userMessages.map(message => message.content).join('\n\n');
    const payload = JSON.stringify({
        model: OLLAMA_MODEL,
        prompt,
        system: systemMessage ? systemMessage.content : undefined,
        stream: false,
        format: 'json',
        think: false,
        options: {
            num_predict: 1200,
            temperature: 0.2
        }
    });
    const url = new URL(OLLAMA_BASE_URL);
    // Ollama typical endpoint for generation
    const path = `${url.pathname.replace(/\/$/, '')}/api/generate`;
    const isHttps = url.protocol === 'https:';
    const options = {
        hostname: url.hostname,
        port: url.port || (isHttps ? 443 : 80),
        path,
        method: 'POST',
        headers: {
            'Content-Type': 'application/json',
            'Content-Length': Buffer.byteLength(payload)
        },
        timeout: OLLAMA_TIMEOUT_MS
    };

    const client = isHttps ? https : http;

    return new Promise((resolve, reject) => {
        const req = client.request(options, res => {
            let data = '';
            res.on('data', chunk => data += chunk);
            res.on('end', () => {
                if (res.statusCode >= 200 && res.statusCode < 300) {
                    try {
                        const parsed = JSON.parse(data);
                        // Try common Ollama response shapes
                        let text = null;
                        if (parsed.output && Array.isArray(parsed.output) && parsed.output.length) {
                            text = parsed.output[0];
                        } else if (parsed.results && Array.isArray(parsed.results) && parsed.results[0] && parsed.results[0].content && Array.isArray(parsed.results[0].content)) {
                            text = parsed.results[0].content.join('\n');
                        } else if (parsed.response) {
                            text = parsed.response;
                        } else if (typeof parsed === 'string') {
                            text = parsed;
                        } else {
                            // Fallback: try to find first string in object
                            const findString = obj => {
                                if (!obj) return null;
                                if (typeof obj === 'string') return obj;
                                if (Array.isArray(obj)) return obj.map(findString).find(Boolean) || null;
                                if (typeof obj === 'object') return Object.values(obj).map(findString).find(Boolean) || null;
                                return null;
                            };
                            text = findString(parsed);
                        }

                        resolve(text || '');
                    } catch (e) {
                        reject(new Error('Invalid AI response'));
                    }
                } else {
                    reject(new Error(`AI API error ${res.statusCode}`));
                }
            });
        });
        req.on('error', err => {
            // map network errors to friendly message
            if (err.code === 'ECONNREFUSED' || err.code === 'ENOTFOUND') {
                reject(new Error('Локальний AI-сервіс недоступний. Переконайтеся, що Ollama запущено.'));
            } else {
                reject(err);
            }
        });
        req.on('timeout', () => { req.destroy(new Error('Локальний AI-сервіс не відповів вчасно. Спробуйте ще раз або виберіть компактнішу модель.')); });
        req.write(payload);
        req.end();
    });
}

function buildSystemPrompt() {

Analyze only the provided data and never invent values, facts, causes, or business details. Separate observed facts from assumptions; if a cause is not proven by the data, say "можливим фактором може бути...". Use correct terms: revenue = виручка, profit = прибуток, profitability = рентабельність, asset_turnover = оборотність активів. Do not call revenue or profitability the same thing. The factor section is a sensitivity scenario for a 1% change, not proof of the actual historical contribution. Explain which factor has greater impact only when the provided impact values differ; if they are equal, state that the scenario impacts are equal. Do not recommend actions based on invented causes. If there are no negative changes, explicitly say that negative dynamics were not identified. Return exactly these JSON keys: summary, positiveFactors, negativeFactors, risks, recommendations, factorAnalysisExplanation. Keep the result concise and practical.`;
}

function negativeTrendLabels(deltas) {
    const labels = {
        revenue: 'Зменшення виручки',
        profit: 'Зменшення прибутку',
        assets: 'Зменшення активів',
        profitability: 'Зниження рентабельності',
        liquidity: 'Зниження ліквідності',
        asset_turnover: 'Зниження оборотності активів'
    };

    return Object.keys(labels)
        .filter(key => deltas[key] != null && deltas[key] < 0)
        .map(key => `${labels[key]} на ${Math.abs(deltas[key])}% за аналізований період`);
}

async function analyzePeriod(startYear, endYear) {
    // fetch rows
    const rows = await knex('financial_indicators').whereBetween('year', [startYear, endYear]).orderBy('year', 'asc');
    if (!rows || rows.length < 2) throw new Error('Not enough data for the requested period');

    const first = rows[0];
    const last = rows[rows.length - 1];

    const ctx = {
        period: { startYear, endYear },
        first: { year: first.year, revenue: Number(first.revenue), profit: Number(first.profit), assets: Number(first.assets), profitability: Number(first.profitability), liquidity: first.liquidity ? Number(first.liquidity) : null, asset_turnover: first.asset_turnover ? Number(first.asset_turnover) : null },
        last: { year: last.year, revenue: Number(last.revenue), profit: Number(last.profit), assets: Number(last.assets), profitability: Number(last.profitability), liquidity: last.liquidity ? Number(last.liquidity) : null, asset_turnover: last.asset_turnover ? Number(last.asset_turnover) : null }
    };

    // compute simple deltas where possible
    const deltas = {};
    ['revenue', 'profit', 'assets', 'profitability', 'liquidity', 'asset_turnover'].forEach(key => {
        const a = ctx.first[key];
        const b = ctx.last[key];
        if (a != null && b != null && a !== 0) {
            deltas[key] = +(((b - a) / Math.abs(a)) * 100).toFixed(2);
        } else {
            deltas[key] = null;
        }
    });

    // factor analysis using existing service for the last year
    const factorRes = factorService.analyze(ctx.last.assets, ctx.last.asset_turnover);
    const analysisContext = {
        context: ctx,
        deltas,
        factor: {
            ...factorRes,
            interpretation: 'Сценарна чутливість виручки при збільшенні кожного фактора на 1%; це не фактичний внесок фактора в історичну зміну.'
        }
    };

    const messages = [
        { role: 'system', content: buildSystemPrompt() },
        { role: 'user', content: `Context JSON:\n${JSON.stringify(analysisContext, null, 2)}` }
    ];

    const aiText = await callOllama(messages);
    const parsed = safeParseJson(aiText || '');
    if (!parsed) throw new Error('AI returned non-JSON or malformed response');

    // Basic validation of expected keys
    const required = ['summary', 'positiveFactors', 'negativeFactors', 'risks', 'recommendations', 'factorAnalysisExplanation'];
    for (const k of required) {
        if (!(k in parsed)) {
            const returnedKeys = Object.keys(parsed).join(', ') || '(none)';
            throw new Error(`AI response missing key: ${k}; returned keys: ${returnedKeys}`);
        }
    }

    const observedNegativeFactors = negativeTrendLabels(deltas);
    parsed.negativeFactors = Array.isArray(parsed.negativeFactors) ? parsed.negativeFactors : [];
    observedNegativeFactors.forEach(factor => {
        if (!parsed.negativeFactors.some(item => String(item).toLowerCase().includes(factor.toLowerCase().split(' на ')[0]))) {
            parsed.negativeFactors.unshift(factor);
        }
    });
    if (parsed.negativeFactors.length === 0) {
        parsed.negativeFactors.push('За наданими показниками негативної динаміки не виявлено');
    }

    // attach meta
    return { meta: { startYear, endYear, requestedAt: new Date().toISOString() }, input: { ctx, deltas, factor: factorRes }, result: parsed };
}

async function explainKpi(kpi, year) {
    // fetch requested year plus previous for context
    const y = Number(year);
    if (!y) throw new Error('Invalid year');
    const rows = await knex('financial_indicators').whereIn('year', [y - 1, y]).orderBy('year', 'asc');
    if (!rows || rows.length === 0) throw new Error('No data for requested year');
    const target = rows.find(r => r.year === y) || rows[rows.length - 1];
    const prev = rows.find(r => r.year === y - 1) || null;

    const units = {
        revenue: 'грошові одиниці',
        profit: 'грошові одиниці',
        profitability: '%',
        assets: 'грошові одиниці',
        liquidity: 'коефіцієнт',
        asset_turnover: 'коефіцієнт оборотності'
    };
    const value = target[kpi] !== undefined ? Number(target[kpi]) : null;
    const previous = prev && prev[kpi] !== undefined ? Number(prev[kpi]) : null;
    const ctx = {
        year: y,
        value,
        previous,
        unit: units[kpi] || 'не визначено',
        change: value != null && previous != null ? +(value - previous).toFixed(4) : null,
        changePercent: value != null && previous != null && previous !== 0 ? +(((value - previous) / Math.abs(previous)) * 100).toFixed(2) : null
    };

    const messages = [
        { role: 'system', content: buildSystemPrompt() },
        { role: 'user', content: `Explain the KPI '${kpi}' for year ${y} based only on this JSON:\n${JSON.stringify({ kpi, ctx }, null, 2)}` }
    ];

    const aiText = await callOllama(messages);
    const parsed = safeParseJson(aiText || '');
    if (!parsed) throw new Error('AI returned non-JSON or malformed response');
    // Expected fields in explain: meaning, dynamics, assessment, possibleCauses, conclusion
    return { meta: { year: y }, input: ctx, result: parsed };
}

async function register({ email, password, name, role = 'Analyst' }) {
    // Basic validation
    if (!email || !password) throw new Error('Email and password are required');

    const existing = await findByEmail(email);
    if (existing) throw new Error('Email already exists');

    const hashed = bcrypt.hashSync(password, 10);
    const [id] = await knex('users').insert({ email, password: hashed, name, role });
    const user = await knex('users').where({ id }).first();
    delete user.password;
    return user;
}

function generateToken(user) {
    const payload = { id: user.id, email: user.email, role: user.role };
    return jwt.sign(payload, JWT_SECRET, { expiresIn: TOKEN_EXP });
}

async function login(email, password) {
    if (!email || !password) throw new Error('Email and password are required');
    const user = await findByEmail(email);
    if (!user) throw new Error('Invalid credentials');
    const ok = bcrypt.compareSync(password, user.password);
    if (!ok) throw new Error('Invalid credentials');
    const token = generateToken(user);
    delete user.password;
    return { token, user };
}

// Service for simple factor analysis

function analyze(fixedAssets, assetTurnover) {
    fixedAssets = Number(fixedAssets) || 0;
    assetTurnover = Number(assetTurnover) || 0;
    const revenue = +(fixedAssets * assetTurnover).toFixed(2);

    // Sensitivity: how revenue changes with 1% change in each factor
    const delta = 0.01;
    const revFixedUp = +((fixedAssets * (1 + delta)) * assetTurnover).toFixed(2);
    const revTurnUp = +(fixedAssets * (assetTurnover * (1 + delta))).toFixed(2);
    const impactFixed = +((revFixedUp - revenue).toFixed(2));
    const impactTurn = +((revTurnUp - revenue).toFixed(2));

    const explanation = `Revenue = FixedAssets * AssetTurnover. При зростанні FixedAssets на 1% до ${+(fixedAssets * (1 + delta)).toFixed(2)}, дохід зміниться на ${impactFixed}. При зростанні AssetTurnover на 1% до ${+(assetTurnover * (1 + delta)).toFixed(4)}, дохід зміниться на ${impactTurn}.`;

    return { fixedAssets, assetTurnover, revenue, impactFixed, impactTurn, explanation };
}

function findSystemFont() {
    const candidates = [];
    if (process.platform === 'win32') {

        candidates.push(path.join(windir, 'Fonts', 'arial.ttf'));
        candidates.push(path.join(windir, 'Fonts', 'arialuni.ttf'));
        candidates.push(path.join(windir, 'Fonts', 'arialbd.ttf'));
        candidates.push(path.join(windir, 'Fonts', 'tahoma.ttf'));
        candidates.push(path.join(windir, 'Fonts', 'verdana.ttf'));
    } else if (process.platform === 'darwin') {
        candidates.push('/Library/Fonts/Arial.ttf');
        candidates.push('/Library/Fonts/Helvetica.ttf');
    } else {
        candidates.push('/usr/share/fonts/truetype/dejavu/DejaVuSans.ttf');
        candidates.push('/usr/share/fonts/truetype/liberation/LiberationSans-Regular.ttf');
        candidates.push('/usr/share/fonts/truetype/freefont/FreeSans.ttf');
    }
    for (const p of candidates) {
        try { if (fs.existsSync(p)) return p; } catch (e) { }
    }
    return null;
}

async function generatePdf(name, title, rows) {

import React, { createContext, useState, useContext, useEffect } from 'react';
import api from '../services/api';

const AuthContext = createContext();

export const AuthProvider = ({ children }) => {
    const [token, setToken] = useState(localStorage.getItem('token'));
    const [user, setUser] = useState(() => {
        try {
            const raw = localStorage.getItem('user');
            return raw ? JSON.parse(raw) : null;
        } catch (e) { return null; }
    });

    // Ensure token is applied synchronously for initial requests
    try { if (token) api.setToken(token); } catch (e) { }

    useEffect(() => {
        api.setToken(token);
        if (token) {
            // if user not set, try to fetch profile later
        }
    }, [token]);

    const login = async (email, password) => {
        const res = await api.post('/auth/login', { email, password });
        const data = res.data;
        setToken(data.token);
        setUser(data.user);
        api.setToken(data.token);
        localStorage.setItem('token', data.token);
        localStorage.setItem('user', JSON.stringify(data.user));
        return data;
    };

    const logout = () => {
        setToken(null);
        setUser(null);
        localStorage.removeItem('token');
        localStorage.removeItem('user');
        api.setToken(null);
    };

    return (
        <AuthContext.Provider value={{ token, user, login, logout }}>
            {children}
        </AuthContext.Provider>
    );
};

export const useAuth = () => useContext(AuthContext);

import React, { useState } from 'react';
import api from '../services/api';
import Spinner from '../components/Spinner';
import { toast } from 'react-toastify';

export default function AIAnalyst() {
    const [loading, setLoading] = useState(false);
    const [result, setResult] = useState(null);
    const [period, setPeriod] = useState({ startYear: '', endYear: '' });

    const runAnalysis = async () => {
        setLoading(true);
        setResult(null);
        try {
            const body = {};
            if (period.startYear && period.endYear) body.startYear = Number(period.startYear), body.endYear = Number(period.endYear);
            const res = await api.post('/ai/analyze', body, {
                timeout: 120000
            });
            setResult(res.data);
        } catch (e) {
            console.error(e);
            toast.error(e.response?.data?.message || e.message || 'AI error');
        } finally { setLoading(false); }
    };

    return (
        <div>
            <h3>AI-аналітик</h3>
            <p className="text-muted">Інтерпретація наявних фінансових показників системою AI.</p>

            <div className="card p-3 mb-3">
                <div className="row g-2 align-items-end">
                    <div className="col-auto">
                        <label className="form-label">Початковий рік</label>
                        <input className="form-control" value={period.startYear} onChange={e => setPeriod({ ...period, startYear: e.target.value })} />
                    </div>
                    <div className="col-auto">
                        <label className="form-label">Кінцевий рік</label>
                        <input className="form-control" value={period.endYear} onChange={e => setPeriod({ ...period, endYear: e.target.value })} />
                    </div>
                    <div className="col-auto">
                        <button className="btn btn-primary" disabled={loading} onClick={runAnalysis}>{loading ? 'AI аналізує...' : '✨ Виконати AI-аналіз'}</button>
                    </div>
                </div>
            </div>

            {loading && <div className="card p-3 mb-3"><Spinner /></div>}

            {result && (
                <div className="card p-3">
                    <h6>Резюме</h6>
                    <p>{result.result?.summary}</p>

                    <div className="row">
                        <div className="col-md-6">
                            <h6>Позитивні фактори</h6>

import React, { useEffect, useState } from 'react';
import api from '../services/api';
import { useAuth } from '../auth/AuthProvider';

import Spinner from '../components/Spinner';
import KpiCard from '../components/KpiCard';

export default function Inventory() {
    const { user } = useAuth();
    const [products, setProducts] = useState([]);
    const [categories, setCategories] = useState([]);
    const [filters, setFilters] = useState({ search: '', category: '', lowThreshold: 50, page: 1, limit: 50 });
    const [meta, setMeta] = useState({ page: 1, limit: 50, total: 0 });
    const [loading, setLoading] = useState(false);
    const [editing, setEditing] = useState({});

    useEffect(() => { fetchCategories(); loadProducts(1); }, []);

    const totalSkus = products.length;
    const totalUnits = products.reduce((s, p) => s + (Number(p.stock) || 0), 0);
    const totalValue = products.reduce((s, p) => s + ((Number(p.stock) || 0) * (Number(p.price) || 0)), 0).toFixed(2);
    const lowCount = products.filter(p => (Number(p.stock) || 0) < filters.lowThreshold).length;
    const reorderList = products.filter(p => (Number(p.stock) || 0) < filters.lowThreshold).slice(0, 8).map(p => ({ id: p.id, name: p.name, stock: p.stock, recommended: Math.max(0, 100 - (Number(p.stock) || 0)) }));

    const fetchCategories = async () => {
        try {
            const res = await api.get('/categories');
            setCategories(res.data || []);
        } catch (err) { console.error(err); }
    };

    const loadProducts = async (page = 1) => {
        setLoading(true);
        try {
            console.log('[Inventory] loadProducts called with page:', page, 'filters:', filters);
            // Don't filter by lowThreshold in API - that's just for display
            const params = { page, limit: filters.limit, search: filters.search, category: filters.category };
            const res = await api.get('/products', { params });
            console.log('[Inventory] API response:', res.data);
            setProducts(res.data.data || []);
            setMeta(res.data.meta || { page, limit: filters.limit, total: 0 });
        } catch (err) {
            console.error('[Inventory] Error loading products:', err);
            toast.error('Помилка завантаження продуктів');
        }
        finally {
            setLoading(false);
        }
    };

    const downloadCSV = (rows, filename = 'запаси_товарів.csv') => {
        if (!rows || !rows.length) { toast.info('Немає даних для експорту'); return; }
        const headers = ['ID', 'Назва', 'Категорія', 'Ціна', 'Собівартість', 'Залишок', 'Одиниця'];
        const keys = ['id', 'name', 'category', 'price', 'cost_price', 'stock', 'unit'];
        const csvRows = [headers.join(',')];
        for (const r of rows) {
            const line = keys.map(k => {
                const v = r[k] === null || r[k] === undefined ? '' : String(r[k]).replace(/"/g, '""');
                return `"${v}"`;
            }).join(',');
            csvRows.push(line);
        }
        const csv = csvRows.join('\r\n');
        const blob = new Blob([csv], { type: 'text/csv;charset=utf-8;' });
        const url = URL.createObjectURL(blob);
        const a = document.createElement('a');
        a.href = url; a.download = filename; a.click();
        URL.revokeObjectURL(url);
    };

    const exportCsv = () => {
        const data = products.map(p => ({ id: p.id, name: p.name, category: p.category_name, price: p.price, cost_price: p.cost_price, stock: p.stock, unit: p.unit }));
        downloadCSV(data, 'запаси_товарів.csv');
    };

    const adjustStock = async (productId) => {
        const val = editing[productId];
        const stock = Number(val);
        if (isNaN(stock)) { toast.error('Неправильне значення'); return; }
        try {
            await api.post('/inventory/adjust', { product_id: productId, stock });
            toast.success('Оновлено');
            loadProducts(meta.page);
        } catch (err) { console.error(err); toast.error('Помилка оновлення'); }
    };

    const gotoPage = (p) => { loadProducts(p); };

    return (
        <div>
            <h3>Склад</h3>
            <p className="text-muted">Огляд наявних товарів, залишків та пропозиції до поповнення.</p>

            <div className="mb-3 kpi-grid">
                <KpiCard title="SKU" value={totalSkus} />
                <KpiCard title="Всього одиниць" value={totalUnits} />
                <KpiCard title="Загальна вартість" value={`${totalValue}`} />
                <KpiCard title="Мало на складі" value={lowCount} />
            </div>

            <div className="card p-3 mb-3">
                <div className="row g-2">
                    <div className="col-md-4">
                        <input className="form-control" placeholder="Пошук..." value={filters.search} onChange={e => setFilters(f => ({ ...f, search: e.target.value }))} />
                    </div>
                    <div className="col-md-3">
                        <select className="form-select" value={filters.category} onChange={e => setFilters(f => ({ ...f, category: e.target.value }))}>
                            <option value="">Всі категорії</option>
                            {categories.map(c => <option key={c.id} value={c.id}>{c.name}</option>)}
                        </select>
                    </div>
                    <div className="col-md-2">
                        <input className="form-control" type="number" value={filters.lowThreshold} onChange={e => setFilters(f => ({ ...f, lowThreshold: Number(e.target.value) }))} />
                    </div>
                    <div className="col-md-3 d-flex gap-2">
                        <button className="btn btn-primary" onClick={() => loadProducts(1)}>Застосувати</button>
                        <button className="btn btn-outline-secondary" onClick={() => { setFilters({ search: '', category: '', lowThreshold: 50, page: 1, limit: 50 }); loadProducts(1); }}>Скинути</button>
                        <button className="btn btn-success" onClick={exportCsv}>Експорт CSV</button>
                    </div>
                </div>
            </div>

            <div className="card p-3">
                <div className="table-responsive">
                    <table className="table table-sm">
                        <thead>
                            <tr><th>ID</th><th>Назва</th><th>Категорія</th><th>Ціна</th><th>Собівартість</th><th>На складі</th><th>Од.</th><th>Дії</th></tr>
                        </thead>
                        <tbody>
                            {loading ? <tr><td colSpan={8}><Spinner /></td></tr> : (

                                    <tr key={p.id} className={p.stock < filters.lowThreshold ? 'low-stock' : ''}>
                                        <td>{p.id}</td>
                                        <td>{p.name}</td>
                                        <td>{p.category_name}</td>
                                        <td>{p.price}</td>
                                        <td>{p.cost_price}</td>
                                        <td>{p.stock}</td>
                                        <td>{p.unit}</td>
                                        <td>
                                            {user?.role === 'Admin' ? (
                                                <div className="d-flex gap-2">
                                                    <input className="form-control form-control-sm" style={{ width: 110 }} value={editing[p.id] ?? ''} onChange={e => setEditing(s => ({ ...s, [p.id]: e.target.value }))} placeholder="Кількість" />
                                                    <button className="btn btn-sm btn-primary" onClick={() => adjustStock(p.id)}>Зберегти</button>

import axios from 'axios';

const baseURL = import.meta.env.VITE_API_URL || 'http://localhost:4000/api';

const instance = axios.create({ baseURL, timeout: 15000 });

// helper to set auth header
instance.setToken = token => {
    if (token) {
        instance.defaults.headers.common['Authorization'] = `Bearer ${token}`;
        console.log('[API] Token set:', token.substring(0, 20) + '...');
    }
    else {
        delete instance.defaults.headers.common['Authorization'];
        console.log('[API] Token cleared');
    }
};

// Apply token synchronously from localStorage so initial requests include it
try {
    const _stored = localStorage.getItem('token');
    if (_stored) {
        instance.defaults.headers.common['Authorization'] = `Bearer ${_stored}`;
        console.log('[API] Token loaded from localStorage:', _stored.substring(0, 20) + '...');
    } else {
        console.log('[API] No token in localStorage');
    }
} catch (e) {
    // ignore (e.g. during SSR or restricted env)
    console.log('[API] Error accessing localStorage:', e.message);
}

// Ensure every request has Authorization header as a fallback to localStorage
instance.interceptors.request.use(config => {
    try {
        const stored = localStorage.getItem('token');
        if (stored) {
            config.headers = config.headers || {};
            if (!config.headers.Authorization && !config.headers.authorization) {
                config.headers.Authorization = `Bearer ${stored}`;
            }
        }
    } catch (e) {
        // ignore
    }
    return config;
});
// Add request interceptor for debugging
instance.interceptors.request.use(
    config => {
        if (config.url.includes('/products')) {
            console.log('[API] Products request:', {
                url: config.url,
                params: config.params,
                headers: config.headers
            });
        }
        return config;
    }
);
instance.interceptors.response.use(
    response => {
        if (response.config.url === '/products') {
            console.log('[API] Products response:', response.data.data ? response.data.data.length : 0, 'items');
        }
        return response;
    },
    error => {
        console.error('[API] Error:', error.response?.status, error.response?.data?.message || error.message);
        return Promise.reject(error);
    }
);

export default instance;

users: id PK, email UNIQUE, password bcrypt, name, role, created_at, updated_at
categories: id PK, name UNIQUE, description, created_at, updated_at
products: id PK, name, category_id -> categories, price, cost_price, stock, unit, barcode, timestamps
sales: id PK, product_id -> products, quantity, unit_price, total_price, sale_date, created_by -> users, timestamps
inventory: id PK, product_id -> products, stock, recorded_at, timestamps
financial_indicators: id PK, year UNIQUE, revenue, profit, assets, profitability, liquidity, asset_turnover, timestamps
reports: id PK, name, type, path, meta JSON, timestamps
Зв’язки: categories 1:N products; products 1:N sales/inventory; users 1:N sales.
