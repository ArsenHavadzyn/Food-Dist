Frontend (Vite + React) for Distributor Analytics MVP

Install & run:

```bash
cd frontend
npm install
npm run dev
```

API base is `http://localhost:4000/api` by default. To change, set `VITE_API_URL` environment variable.
Build (production):

```bash
npm run build
```

Theme and styling notes:
- Toggle the light/dark theme from the sidebar; variables are defined in `src/index.css`.
