# Automated Distributor Analytics

Це навчальний проект, створений для демонстрації повнофункціональної веб-системи обліку продажів, складу та фінансової аналітики для дистриб'юторів.

## Огляд проекту

Проект складається з двох частин:

- `backend/` — Node.js + Express API з SQLite, JWT авторизацією, ролями користувачів та можливістю генерації звітів у PDF/Excel.
- `frontend/` — React + Vite клієнтська частина з інтерактивною панеллю, графіками, таблицями та підтримкою світлої/темної теми.

## Особливості

- Авторизація через JWT
- Рольова модель: `Admin` та `Analyst`
- Адмінська сторінка для створення, редагування і видалення користувачів
- Продажі з фільтрацією, сортуванням і посторінковою навігацією
- Аналітика продажів з графіками та KPI
- Управління складом із підрахунком залишків та експортом CSV
- Факторний аналіз, фінансові розрахунки та генерація звітів
- Підтримка української мови в інтерфейсі та демонстраційних даних

## Технології

- Backend: Node.js, Express, Knex, SQLite, JWT, bcrypt, PDFKit, ExcelJS
- Frontend: React, Vite, React Router, Axios, Bootstrap, Recharts, React Toastify
- Інструменти: concurrently для одночасного запуску серверів

## Підготовка та запуск

### 1. Встановити залежності

```powershell
npm run install:all
```

### 2. Запустити сервери під час розробки

```powershell
npm run start:all
```

### 3. Відкрити додаток

- Фронтенд: `http://localhost:5173`
- Бекенд API: `http://localhost:4000`

## Скрипти

### В корені проекту

- `npm run install:all` — встановити залежності для `backend` та `frontend`
- `npm run dev:backend` — запустити бекенд у режимі розробки
- `npm run dev:frontend` — запустити фронтенд у режимі розробки
- `npm run start:all` — одночасно запустити фронтенд і бекенд
- `npm test` — запустити 14 автоматизованих тестів бізнес-розрахунків бекенду

### Backend

Перейти до `backend/`:

- `npm run dev` — запустити сервер з `nodemon`
- `npm test` — запустити тести розрахунків фінансових показників і факторного аналізу
- `npm run migrate` — виконати міграції бази даних
- `npm run seed` — заповнити демо-даними

Тести можна запускати з кореня проєкту командою `npm test`. Вони використовують вбудований test runner Node.js та не потребують запуску сервера або підключення до бази даних.

### Frontend

Перейти до `frontend/`:

- `npm run dev` — запустити Vite на локальному сервері
- `npm run build` — зібрати продакшн-бандл
- `npm run preview` — переглянути зібрану версію

## AI-аналітик

Доданий модуль AI-аналітика: бекенд формує контекст з наявних фінансових показників та факторного аналізу і відправляє його зовнішній AI API для інтерпретації.


Налаштування environment variables (див. `.env.example`):


Ця реалізація використовує локальний Ollama через REST API (жодних платних API та ключів). React не звертається безпосередньо до Ollama — всі запити проходять через бекенд. AI не має прямого доступу до БД — бекенд збирає дані, формує контекст і передає лише ці значення для пояснення. Результат повертається у структурованому JSON з полями: `summary`, `positiveFactors`, `negativeFactors`, `risks`, `recommendations`, `factorAnalysisExplanation`.

## Локальний AI-аналітик (Ollama)

Цей проєкт використовує локальний Ollama REST API для безплатного запуску AI-моделі локально. React не звертається безпосередньо до Ollama — усе проходить через бекенд.

Кроки (коротко):

1. Встановіть Ollama за офіційною інструкцією: https://ollama.com/docs
2. Завантажте рекомендовану модель (приклад):

```powershell
ollama pull <model-name>
```

3. Запустіть Ollama локально (див. офіційну інструкцію); зазвичай:

```powershell
ollama serve
```

4. Налаштуйте `.env` (див. `.env.example`):

```text
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=<model-name>
```

5. Запустіть бекенд і фронтенд як зазвичай.

Тестування: Виконайте `POST /api/ai/analyze` або натисніть кнопку `✨ Виконати AI-аналіз` у Dashboard.

Примітка: назву моделі вибирайте відповідно до моделі, яку ви завантажили в Ollama. Немає API key — все локально.
