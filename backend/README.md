Backend (Express + SQLite) for Distributor Analytics

Quick start:

1. Install dependencies

```powershell
cd backend
npm install
```

2. Create `.env` from `.env.example` and adjust `JWT_SECRET` if desired.

3. Run migrations and seeds (Knex):

```powershell
npx knex migrate:latest --knexfile knexfile.js
npx knex seed:run --knexfile knexfile.js
```

4. Start dev server:

```powershell
npm run dev
```

API docs (Swagger): http://localhost:4000/api/docs

Useful endpoints:
- `POST /api/auth/login` — login (use demo users in seeds)
- `GET /api/analytics/dashboard` — dashboard KPIs
- `GET /api/sales` — list sales
- `POST /api/reports/generate/pdf` — generate PDF
- Swagger and Authorization:
	- API docs are available at `http://localhost:4000/api/docs`.
	- The docs include a Bearer (JWT) security scheme — obtain a token via `POST /api/auth/login` and use it when calling protected endpoints.

- `POST /api/reports/export/sales-csv` — generate CSV export for sales (body: filters)

Files generated by reports are stored in `public/reports` and recorded in `reports` table.
